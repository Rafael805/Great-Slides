The Hidden Failure Mode

4 Reasons a Post Gets Rejected

Filter Set Mismatch

Full PII reveals a field that fails the buyer's filter — too old, wrong city, wrong vehicle.

Duplicate Detection

Buyer's CRM already has this lead. Auto-rejected before it ever gets contacted.

Lead Scoring / TCPA Fail

Third-party API check kills it: bad phone, low score, TCPA non-compliant.

Missing Required Fields

Post arrives malformed or incomplete. Buyer's system rejects automatically.
